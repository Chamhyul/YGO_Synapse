Privacy Policy (개인정보 처리방침)

YGO Synapse(이하 '서비스')는 사용자의 개인정보를 소중히 여기며, 개인정보보호법 등 관련 법령을 준수하고 있습니다. 본 웹앱이 구글 로그인 및 유튜브 API를 통해 수집하는 정보와 그 사용 목적에 대해 아래와 같이 안내합니다.

1. 수집하는 개인정보 항목

  • 계정 정보: 구글 로그인 시 제공받는 고유 식별자(UID), 닉네임, 프로필 이미지 (이메일 주소 등 연락처 정보는 별도로 저장하지 않습니다.)
  • 구글 사용자 데이터: 유튜브 채널 멤버십 상태 확인을 위한 계정 정보 (서비스 기능 이용을 위한 선택 사항)
  • 서비스 이용 데이터: 카드 정보(이름, 번호), 보유 수량, 카드를 보관하는 장소(보관함)의 이름 등 사용자가 직접 입력한 일체의 데이터

2. 개인정보의 수집 및 이용 목적

  • 사용자 식별 및 개인화된 카드 관리 환경 제공
  • 유튜브 멤버십 상태 연동을 통한 광고 제거 등 프리미엄 혜택 제공
  • 사용자 데이터의 클라우드 저장 및 기기간 동기화 지원

3. Google 데이터 사용 정책 준수 (Limited Use Policy)

YGO Synapse의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 준수하며, 특히 다음의 제한적 사용(Limited Use) 요구사항을 엄격히 지킵니다.

- 구글 로그인 및 유튜브 API를 통해 획득한 데이터는 서비스의 핵심 기능 제공 및 개선을 위해서만 사용됩니다.
- 사용자의 명시적인 동의 없이 구글 데이터를 제3자에게 판매하거나 마케팅/광고 목적으로 절대 공유하지 않습니다.
- 사용자의 비밀번호나 금융 정보 등 민감한 데이터는 어떠한 경우에도 수집하거나 요청하지 않습니다.

4. 개인정보의 보유 및 이용 기간

사용자가 서비스를 탈퇴하거나 수집 동의를 철회할 경우 해당 데이터는 지체 없이 영구 삭제됩니다. 또한 마지막 접속일로부터 1년 동안 로그인 이력이 없는 경우, 안정적인 데이터 관리를 위해 해당 사용자 데이터를 별도의 고지 없이 파기할 수 있습니다.

5. 개인정보 처리 위탁 및 보안

본 서비스는 데이터 보관 및 서버 운영을 위해 아래와 같이 외부 전문 업체에 개인정보 처리를 위탁하고 있습니다.
- 수탁자: Google LLC (Google Cloud / Firebase)
- 위탁 내용: 서비스 제공을 위한 사용자 데이터 보관 및 서버 인프라 유지관리
- 보관 위치: 대한민국 (asia-northeast3 리전)
