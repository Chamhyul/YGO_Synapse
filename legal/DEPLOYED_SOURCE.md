# 프로젝트 소스코드·실행 안내

[GitHub 소스 저장소](https://github.com/Chamhyul/YGO_Synapse)

프로젝트 소스는 GitHub 저장소와 Git 이력으로 제공합니다. 이 사이트에는 별도의 소스 압축본·체크섬이나 버전별 다운로드 파일을 누적하지 않습니다. 저장소의 브랜치·커밋을 선택해 코드를 확인하거나 Git으로 복제할 수 있습니다.

## 구성과 실행

웹 HTML·JavaScript·CSS는 `public/`, 서버 함수는 `functions/`, 카드 모듈 원본은 `card-service/src/`에 있습니다. 의존성은 각 `package.json`·`package-lock.json`에 고정하며 Docker 구성과 반복 가능한 검사 도구도 저장소에 포함합니다. 개발·검증은 단일 저장소에서 진행하고 Functions용 카드 생성 패키지는 원본 모듈과 대조합니다.

Node 24와 잠금 의존성을 사용합니다. 실행·에뮬레이터·배포에는 사용자가 자신의 Firebase 프로젝트·환경·시크릿·권한을 별도로 준비해야 합니다. GitHub 게시와 운영 배포는 별도이며, 저장소의 최신 코드가 모든 운영 함수에 동시에 적용됐다고 의미하지 않습니다. 운영 소스를 대조할 때는 실제 배포 함수·웹 자산과 해당 커밋을 확인합니다.
