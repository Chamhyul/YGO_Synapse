# Instructions

Always communicate with the user in Korean. This includes:
1. Direct responses in chat.
2. Thoughts and reasoning processes.
3. Artifacts like implementation plans and walkthroughs.
4. Explanations of code changes.

# 지침

사용자와의 모든 소통은 한국어로 진행해야 합니다. 다음 항목이 포함됩니다:
1. 채팅창에서의 직접적인 답변.
2. 생각(Thought) 및 추론 과정.
3. 구현 계획서(Implementation Plan), 워크스루(Walkthrough) 등의 아티팩트.
4. 코드 변경 사항에 대한 설명.
