# 카드 서비스 작업 지침

- 한국어로 소통한다. 파일 변경·커밋·푸시·운영 변경은 각각 사용자가 승인한 범위에서만 진행한다.
- 기존 변경을 보존한다. src/가 카드 코드 원본이며 호환 생성본은 직접 편집하지 않는다.
- 로컬 실행·자동 검사는 Docker에서 수행하고 기존 서버를 중지/재시작하지 않는다.
- runtime/은 제한된 카드 읽기 API다. 수집·저장·관리 코드를 자동으로 이 서버에 노출하지 않는다.
- 인증·조회 경로·필드·응답 버전·오류 계약과 카드 외 데이터 접근 차단을 유지한다.
- 비밀값·사용자 데이터·private/·비공개 docs/는 Git·이미지·배포 산출물에 포함하지 않는다.
- 날짜별 기록은 비공개 private/YYYY.MM.DD/에 보관한다. 합성/에뮬레이터 검증을 실제 OIDC·IAM·운영 검증으로 기록하지 않는다.
- 현재 원본은 기존 `YGO_Synapse` 단일 저장소다. 같은 Firebase 프로젝트에서 카드 데이터는 Firestore, 사용자·인벤토리는 RTDB로 전환하는 목표를 따른다. Authentication·파일 Storage와 전체 기능/API 호환을 유지한다. 저장소 분리용 준비본은 보존 참고 자료이며 일상 개발·자동 동기화 대상으로 사용하지 않는다. 현재 구현과 미구현 목표를 구분하고 실제 전환·IAM·데이터·배포는 별도 승인 후 수행한다.
