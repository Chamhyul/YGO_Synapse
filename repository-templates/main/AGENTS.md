# 보존용 분리 저장소 템플릿 작업 지침

- 한국어로 소통한다. 파일 변경·커밋·푸시·운영 변경은 각각 사용자가 승인한 범위에서만 진행한다.
- 작업 전 Git 상태를 확인하고 기존 미커밋 변경과 다른 세션의 작업을 보존한다.
- 로컬 실행·자동 검사는 Docker에서 수행한다. 기존 서버·컨테이너는 사용자 종료 지시 없이 재시작하지 않는다.
- 카드 호환 패키지는 생성본이다. 직접 수정하지 않고 단일 저장소의 card-service/src 원본과 해시를 확인한 산출물로 갱신한다.
- API 이름·입력·응답·인증·키/CORS/쿼터 계약을 유지한다. 읽기 장애를 미발견 성공으로 바꾸지 않는다.
- 비밀값·사용자 데이터·private/·비공개 docs/는 Git·이미지·배포 산출물에 포함하지 않는다.
- 날짜별 작업/검증 기록은 비공개 private/YYYY.MM.DD/에 보관한다. 실제 클라우드 검증과 합성 Docker 검증을 구분한다.
- operations/workflows/의 파일은 비활성 참고본이다. 승인 없이 활성화하거나 배포 설정을 연결하지 않는다.
- 현재 원본은 기존 `YGO_Synapse` 단일 저장소다. 같은 Firebase 프로젝트에서 카드 데이터는 Firestore, 사용자·인벤토리는 RTDB로 전환하는 목표를 따른다. Authentication·파일 Storage와 전체 기능/API 호환을 유지한다. 저장소 분리용 준비본은 보존 참고 자료이며 일상 개발·자동 동기화 대상으로 사용하지 않는다. 현재 구현과 미구현 목표를 구분하고 실제 전환·IAM·데이터·배포는 별도 승인 후 수행한다.
